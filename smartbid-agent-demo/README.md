# 智标协同 Agent Demo

一个无需后端即可演示的中文多 Agent 招投标工作台。

## 演示内容

- 招标文件导入与项目创建
- 招标解析、企业知识检索、方案编制、报价测算、合规评审五类 Agent
- 实时工作流进度和思考日志
- 合规矩阵、技术方案、报价清单、模拟评分四类成果
- 可点击的重新运行、成果切换、文件导入和 Agent 问答

## 运行

直接打开 `index.html`，或在目录内启动任意静态文件服务器。

> 当前版本是产品演示原型，使用模拟数据。接入真实大模型时，可将五类 Agent 分别映射为编排节点，并连接企业知识库、报价规则和审批流。
